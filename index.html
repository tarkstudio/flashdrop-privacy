2. Architecture Overview: Offline-First, Zero-Server Design

FlashDrop operates on a purely offline peer-to-peer (P2P) architecture. This is a foundational design principle, not merely a configuration choice.

2.1 What This Means for Your Data

  • No remote servers: FlashDrop does not operate, own, lease, or use any backend servers, cloud APIs, or data centers to route, store, or process your files.
  • No data uploads: At no point does the Application transmit your files, file names, file metadata, usage patterns, analytics events, device identifiers, or any other information to the Developer or to any third-party remote service.
  • No accounts required: FlashDrop requires no user registration, account creation, or identity verification. No username, password, email address, or personal identifier is collected by the Developer.
  • Local socket only: All file transfers occur directly between two devices on the same local network segment via raw TCP/UDP sockets, Wi-Fi Direct protocols, or local hotspot streams. Data never traverses the public internet.

2.2 Peer-to-Peer Transfer Model

When you transfer a file using FlashDrop:

  1. Your device opens a local socket (e.g., on 192.168.x.x or a link-local address) and advertises availability within the local network only.
  2. A receiving device discovers this socket via mDNS/Bonjour broadcast, QR code scan, or manual IP entry — all local operations.
  3. The file is streamed directly from the sending device's local storage to the receiving device's local storage via the established socket.
  4. The Developer's systems are never involved. No data is routed through us at any stage.

3.1 Location Permission Clarification

Android's Wi-Fi scanning API (WifiManager.startScan(), WifiP2pManager) mandates the ACCESS_FINE_LOCATION permission at the operating system level. FlashDrop does not read, record, process, or transmit your geographic location. This permission is an OS-enforced prerequisite for Wi-Fi Direct peer discovery and is used for no other purpose whatsoever.
